# Experience Helper

A Foundry VTT v12 module for Pathfinder 2e v6 system. Allows the Gamemaster to give experience points to player characters via a simple UI.

## Features
- Select party members for XP distribution
- Enter XP amount and distribute to selected characters
- Humorous feedback messages

## Installation
1. Copy the module folder to your Foundry VTT modules directory.
2. Add and activate the module in Foundry VTT.

## Usage
Open the XP Manager from the module menu and distribute XP to your party.
